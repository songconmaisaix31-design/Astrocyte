# 正式实验文档入口

实际运行先读 [V4 日运行任务](../../tasks/M6-V4-daily-operation.md) 和根 [STATUS](../../STATUS.md)，核外部原权威锁、day0、路由与授权。最近核查中原证据根、锁与正式 SQLite 不可用；本轮文档整理未重新查询或恢复它们，不启动补采或模型请求。

[EXPERIMENT](../EXPERIMENT.md) 是原锁定 SHA 对应的正文，开头的 UNLOCKED 是锁前快照文字；正文保持原文，实际锁由外部权威记录决定，不能为修改标题重新生成锁。

| 文件 | 用途 |
| --- | --- |
| [OPERATIONS](OPERATIONS.md) | 原工具命令、数据契约与历史接缝，执行须通过当前日运行门禁 |
| [MODEL_ROUTE](MODEL_ROUTE.md) | 实际路由、预算和原始限制；开发额度读取 RESOURCES |
| [LOSSLESS_A_CANDIDATE](LOSSLESS_A_CANDIDATE.md) | 未激活的历史表示候选，不能据此切换正式配置 |
| [SCORE_TABLES](SCORE_TABLES.md) | 三类独立评分的数据要求 |
| [REPORT_TEMPLATE](REPORT_TEMPLATE.md) | 尚需真实数据填写的成熟报告格式 |
| [DAY0_REPORT](DAY0_REPORT_2026-10-13.md) | 原首日来源、窗口、结果与限制 |

人口、隐私、冻结参数和阶段继承见 [v2.0](../../tasks/M6-validation-v2.md)、[v2.1](../../tasks/M6-validation-v2.1.md)、[v2.2](../../tasks/M6-validation-v2.2.md)、[v3.0](../../tasks/M6-validation-v3.md)。后续修订只覆盖相应条款，未被覆盖的要求保留。新科研八配置方案与原 V4 分别管理。
