## 首次实际运行（保留失败）

2026-10-09，Windows/PowerShell，Node 24.16.0、Go 1.27.2。`node --test tests/s1/acceptance.test.mjs`：4 PASS、4 FAIL、0 skipped，约 5.25 秒。通过的具体场景为并发/同 key 异正文冲突及同源去重、YouTube 别名/无字幕不伪时间戳、Agent 默认拒绝/人类刷新不加热/主动重读仅计一次、坏导出文件修正后同 job/operation 重试恢复。

四个失败均遇到同一真实 DTO 缺陷：合法请求省略可选 `related_refs` 后，`POST /distillations` 返回 `distillation.related_refs: null`，OpenAPI 要求 array。失败消息：`POST /distillations 200 violates OpenAPI: data/distillation/related_refs must be array`。领域构造没有归一该切片，已交 W1 修复；W4 不通过补空数组或放松 schema 绕过。AT01、多版本沉淀重用、候选 CAS 与 later/重启检查在该位置阻断，未执行的后续断言不记通过。

同批 `go test -mod=readonly ./tests/s1` PASS（0.812 秒）；浏览器测试模块 typecheck 与定向 ESLint PASS，浏览器实际执行仍待可消费 UI 源码。已授权 Agent 读取正路径等待项目顶层空间/固定资料范围公共契约；当前默认拒绝的通过不能替代该正路径验收。人工分类、排序与 @ 引用不得自行扩大 Agent 权限，具体用户语义未答复时不冻结测试接口。

## 可重复命令

冻结锁安装后，在仓库根执行：

```powershell
node --test tests/s1/acceptance.test.mjs
go test -mod=readonly ./tests/s1
pnpm --dir web test:e2e s1.spec.ts
```

辅助代码构建当前 `cmd/server`，使用单独临时 API/Vite/SQLite/objects，并关闭仅由本次调用创建的进程句柄。Windows 的重启使用现有 `scripts/process.mjs` 对 owned 子进程终止，再启动同一二进制/数据目录；验证的是持久化重启，不代表优雅退出验收。每个实际 JSON 响应按 OpenAPI 校验，数据库只读核对业务 head、immutable revisions、job payload/caller 和事件，不向产品暴露 SQL/objects。
