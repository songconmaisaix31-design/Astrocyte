# 科研反馈与产品决定

2026-10-19。主控负责统筹；科研事实源为用户论文定位稿v3、实验预注册开发草案v0.1，以及当前科研任务和实际产品证据。

| 事项 | 当前决定 | 依据与后续条件 |
| --- | --- | --- |
| 科研写作与反馈 | 启动独立科研Worker和项目skill，完成初稿、文献核查及研究反馈 | 科研写域独立，不能直接改产品 |
| 论文主张 | 将提出的方法、当前实现、工程验证、正式结果分别表述 | 八配置正式实验尚未执行；现有DAG/前端验收不能证明因果收益 |
| 产品可靠性及权限 | 保持既有边界，研究需求先提交主控决定 | 原生工具关闭、S3两项待答、未知交付不重发、单Mission执行权威保持 |
| 八配置实现与正式实验 | 研究Agent先核当前差距并给出建议，本轮不直接实施 | 共用评分、两更新开关、隔离快照、计量、独立评价和模型/任务清单尚须准确核查 |
| 正式阈值、预算与重复次数 | 保留草案/算例和待确认状态 | 需要试运行方差、计量和用户明确决定；r=5/T=10不能视为正式样本量 |
| 正式V4 | 保持独立、只读 | 现有EXPERIMENT/锁/正式库/automation不随新论文草案变化 |
| 写作语言与作者信息 | 初稿准备英文正文/中文反馈；作者、机构、ORCID待填 | 已异步询问，未答不虚构身份，不提交公开投稿 |
