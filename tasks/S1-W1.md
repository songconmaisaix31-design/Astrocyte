实现 `NewAttentionService(repo, sources, objects, ServiceOptions)`，`Service.Run(ctx)` 有限 Go worker 池及 `ProcessNextJob(ctx)`。Options：`WorkerConcurrency`（默认 2）、`MaxAttempts`（3）、`JobTimeout`（5 分钟）、`AttentionHalfLife`（7 天）、可注入 `Clock`。作业 CAS、operation、payload/caller、取消、显式重试次数与原总时限持续保存；只读导入下载中断可显式重试，未知付费/效果作业不能盲重发。输入导出是固定快照时复用相同作业；远端 URL/本地文件可变时，新明确命令重新只读获取，材料按 canonical source key 与实际 SHA256 去重。外部读取/对象发布不持 SQL 事务，材料版本、作业结果、事件一并提交；命令保存完整回执，同键不同语义冲突。

人工三层记录有真实 `manual` provenance；同输入/配置/问题及定位复用输出，主题资料不足保留待查问题，项目记录目标/资产/预期改进/最小成果/缺失依据。机会草稿、独立 CAS 版本、内容 revision 历史与指向内容版本的反馈保持独立。later 不删除资料，reject 必须有维度理由；四维 null 不变成零。

人类普通 GET 与系统刷新不增加热度；固定/生命周期/收藏理由修改不增加内容 revision。显式采用计独立长期价值，半衰期只影响人类关注。用户新指示后，Agent 所有资料/派生/附件/作业查询默认 `scope_denied`，token 仅证明身份，不授权全库；选择/预设规则契约待用户确认。内部机器使用规则保留，未授权读取不会产生机器或人类使用。无 Principal 的 S0 列表须由 W0 HTTP 可信入口拒绝 Agent。
