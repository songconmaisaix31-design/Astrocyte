## 2. 已采纳条款

### 2.1 能力板核心架构（AgentEvolver）

八类资产纳入统一版本化生命周期：Tool / Skill / Agent / Workflow / Memory / Environment / Connector / Plugin。

每个能力变更必须保持三元组的身份连续：**被修改对象及版本 — 评价证据 — 实际消费者**。评价必须对应被测版本；消费必须指向实际使用该版本的事件或任务。只有候选生成、评价通过或任务最终成功中的一项，不足以证明整条能力积累链成立。

晋级语义沿用 Morphogenesis 的 `quarantine → approved` 既有实现与证据绑定，不把论文中的自评判断替代项目批准。复用前核对其资产、评价和批准边界；Morphogenesis 底层状态字符串为 `quarantined`，本条的 `quarantine` 是语义名称，不据此新增状态或迁移。Astrocyte 经验库的同名人工晋级关口保持。

设计依据：[Wentao Zhang 等，NTU / SMU，2026-10-08，arXiv:2610.11613v1](https://arxiv.org/abs/2610.11613v1)，*AgentEvolver: System-Wide Self-Evolution Through Task Execution*。采纳统一生命周期和变更—评价—消费关联；逐任务归因要求见 §6。

### 2.2 公告板评分函数（含 anti-crowding，Homogenization）

先执行硬过滤链：**权限 → 能力 → depends_on → scope 冲突**（Astrocyte 通道一）。过滤失败的任务不得由高评分重新放行。

通过过滤的候选采用以下评分框架：

```text
score = f(任务属性) + w_a · A(topic) − w_c · C(scope)
C(scope) = g(当前租约数, 活跃 Worker 数, scope 近期事件密度)
```

`A(topic)` 消费 Astrocyte 认知板的当前注意力强度；`C(scope)` 是反拥挤项，用于抑制 Worker 集体涌向热点。`f`、`g` 的具体定义、统计窗口、多主题汇总方式及 `w_a / w_c` 初始值均待 v0.3 正式任务书裁决，不填常量或发布接口。

设计依据：[Prakhar Ganesh 等，McGill / Mila、University of Washington、Apple，2026-10-07，arXiv:2610.09824v1](https://arxiv.org/abs/2610.09824v1)，*Homogenization in Multi-Agent Systems*。论文识别协作中的行为趋同与相关性故障，协作收益可与共同盲点放大并存。“共享评分函数令全体涌向同一高注意力主题”是据此提出的项目风险推论；反拥挤公式是本项目设计，效果须由本项目验收。

### 2.3 双时标信任层（MeshHeal）

| 时标 | 作用 | 落地要求 |
|---|---|---|
| 局部：眼前任务 | 在交付前拦截格式正确但质量退化的灰色故障 | 高影响任务由另一 Worker 轻量同行审查；结论、证据及实际审查成本回流经验库并计入任务预算 |
| 全局：跨任务 | 累积信誉和晋级证据 | 走既有 `quarantine → approved` 链；累计信誉不豁免本次同行审查 |

两层分离，互不替代：一次审查通过不直接晋级；已有信誉不使本次任务免审。高影响任务的判定、审查触发及失败后的处置待正式任务书裁决，不预设自动放行条件。

设计依据：[Keru Chen 等，ASU、University of Houston、Ohio State、Johns Hopkins，2026-09-24，arXiv:2609.29015v1](https://arxiv.org/abs/2609.29015v1)，*MeshHeal: Two-Timescale Self-Healing for Gray Failures in Decentralized LLM Agent Networks*。采纳保护当前任务与跨任务信誉分离的双时标设计；本文不引入论文完整委员会、检测器或恢复探测实现。

### 2.4 租约承诺机制（Waggle 参考）

承诺采用**维持 / 修改 / 撤销**三态语义，作为既有 fencing 租约续期与降级规则的设计输入。

| 承诺语义 | 租约规则设计方向 |
|---|---|
| 维持 | 续期前复核现有权限、依赖、scope 与预算；保持同一任务的承诺连续 |
| 修改 | 记录变更并重查授权和冲突；扩大 scope 或预算仍走既有批准关口 |
| 撤销 | 停止新增动作并按既有交接、释放与 fencing 规则处理；旧持有者不能提交过期成果 |

只参考承诺更新语义，不采用其策略学习。禁 `train` 红线不变；续期时间、降级条件和具体状态转换留到正式任务书裁决。

引用：[Mingxi Zou 等，SAIS、Fudan University、Yunnan University，2026-09-28，arXiv:2609.34136v1](https://arxiv.org/abs/2609.34136v1)，*Waggle: Learning One Anonymous Local Law for Self-Organizing LLM Swarms*。Silo-Bench 在 64 Agent 下成功率 58.2%，瞬时交换和固定规则基线约 15%（作者报告值；作者报告，非跨场景定论；论文 §1 / Table 1），不设为本项目目标。

### 2.5 多样性设计约束（Homogenization）

**异构 harness 不保证观点异构。** 来自不同 Agent 客户端的 Worker 不构成认知多样性保证；该约束为 v0.3 显式设计要求。

公告板上线时登记各 Worker 的实际底层模型分布，展示模型重合度；客户端身份与模型身份分别记录。未核实模型保持未知，不由客户端名称推断。模型分布可见性用于识别重合，不作为多样性验收通过的替代证据。依据沿用 §2.2 的 Homogenization 引用。
