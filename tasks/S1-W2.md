## 真实格式与导入行为

arXiv 接收官方 `abs/pdf/html` URL、现代 ID、旧分类 ID，可含 `vN`。canonical key 为 `arxiv:<无版本ID>`，返回 locator 固定为 API 实际版本；用户已指定 revision 时返回其他 revision 被拒绝。保留完整 PDF 与原始 Atom XML 两个附件，版本化 PDF 作为真实 whole-document locator；摘要明确标注 metadata only，Text 同时包含固定版本 locator 与 PDF SHA256，附件内容变化会影响内容 digest。保留可读取原文，不声称已抽取全文、页码或章节。官方资料：[API 用户手册](https://info.arxiv.org/help/api/user-manual.html)、[API 使用条款](https://info.arxiv.org/help/api/tou.html)。只访问官方 HTTPS 端点，重定向限官方主机，响应有大小限制与超时。

summarize 公共 adapter 使用 `summarize` 自动区分 JSON 与 markdown；内部另支持 `summarize_json/summarize_markdown`。JSON 取实际 `input.url`、`extracted.content`、`summary`、`transcriptSegments[{startMs,endMs?,text}]`；仅有真实片段才保存秒区间，不从摘要/markdown/总时长推算位置。缺 content 而有真实 transcriptSegments 时保留其文本；只剩旧摘要时 mode 为 `existing_summary_only_export`。原始 JSON/markdown 附件保留完整输出及原有未知 usage/cost。普通 URL 去 fragment；YouTube watch/youtu.be/embed/shorts 对应 `youtube:<id>`。导出无工具版本字段，Provenance.Version 使用 `0.21.8-format` 表示实测兼容解析版本，不冒称每份输入的生成器版本。
