## 命题与三臂

命题：Attention → Experience → Memory Consolidation 的纵向交接，使经过 Astrocyte 的 Agent 在真实接力任务上工作更强。V4 独立运行，其胜负均不决定本实验是否运行。

| 臂 | 首条输入 |
|---|---|
| 认知组 | 交接手册 v2：手册 + 认知投影（A 臂既有格式原样复用）+ approved 经验 |
| 传统组 | 项目相关聊天记录 + 文档，在所选上下文预算内构成最强传统输入 |
| 冷启动组 | 仅任务描述 |

比较单位为同一真实任务、同一起始项目状态下的三臂结果；采用任务宏平均，每项任务独立保留失败、未知投递和未完成。不能用已解决任务数的净差代替逐任务归因。

## 评分三权分立

| 指标 | 权威来源 | 必须保留的证据 |
|---|---|---|
| 完成质量 | 人工评分 + 客观适用测试 | 固定评分规则、结果产物、实际命令/结果；人工评分不得由 Agent 代填 |
| 上下文 token 消耗 | 任务收据机判 | 各臂真实用量，缺 usage 保持 unknown；不把估算当实测 |
| 迭代轮次 | 任务收据机判 | 同一预定义轮次单位，派发、发送及返回身份连续 |
| 撞坑命中率 | 事件库回溯 | 输入中的 approved 避坑条目、任务机会与实际命中事件；无适用机会不填成功 |

Interpreter 只起草经验候选，不评价最终质量或替人批准。候选采用 `{pattern, verdict: avoid|prefer|condition, condition, evidence: []event_id}`；进入既有 quarantine，批准权在人。只有实际 approved 条目才可进入认知组输入。失败轨迹优先捕获；同 pattern 多次验证、关联与成熟机制在后续实现规格中裁决，不在本草案发明阈值。
