# S1 Attention integration contract

Owner W0, branch `s1-contract-1009`. The Go boundary is `internal/attention/app/contracts.go`; HTTP schemas are `contracts/openapi.yaml`, generated TS is `web/src/api/schema.d.ts`. Keep prior required fields; all new fields on existing resources are optional in v1.

W1 implements `AttentionService` and owns all state rules. W2 implements `Repository`, `SourceReader`, `ObjectStore`. W0 owns HTTP, migrations and composition. No HTTP SQL or provider calls. No Mission/admission/approval execution in S1.

`Repository.WithTx` runs a callback in a serialized transaction, rolling back on any error. Absent loads/finds return `apierrors.NewNotFound`. Saves compare aggregate Version (distinct from content CurrentRevision/opportunity Revision), with 0 meaning create; conflicting CAS returns `version_conflict`. SaveMaterial preserves all immutable prior revisions, source key uniqueness and (material,digest) uniqueness. SaveOpportunity preserves all prior revisions/reviews. SaveJob persists Payload and Caller separately because their JSON tags intentionally hide these fields from HTTP. Receipt keys are caller ID + command name + Idempotency-Key; receipt Digest binds exact semantic input and Result is the complete response. AppendEvent shares the transaction. Never do source/provider/object I/O inside a callback.

ImportedSource distinguishes actual source Text, Summary and binary Attachments. W1 publishes every object before persisting revision references. The digest identifies actual source bytes, never the caller's assertion. SourceReader validates adapter-derived canonical key/locator and any nonempty supplied digest. `content_digest: ""` and `source_key: ""` request server computation for remote sources; the fields remain required for existing v1 callers. arXiv must preserve a versioned PDF/HTML attachment; an Atom abstract alone is not full paper text. summarize output provenance records the real processing source/version and mode; absent transcript positions remain absent. Manual records are explicitly marked manual and do not pretend to be automatic summaries.

`AttentionService` queries take a trusted Principal where records need identity; existing list methods retain S0 shape. Reads do not count human activity. Explicit human RecordUse increments attention; Agent reads only increment machine use if W1 records them. Principal is never decoded from body fields. Transport uses local human session cookie + CSRF for writes, optional Agent bearer token for reads; Agent-bearing session-bootstrap requests are denied. Admissions remain S2/501. CommandMeta contains request_id, expected_version and transport-supplied idempotency key. Create expected_version is 1; persistence expectedVersion 0 means new row. Existing material content version and opportunity revision are pinned in SourceRef.

Distillation input_refs + stage + processing_config + question form reuse identity. Records carry real manual output; fixed inputs without a new question reuse existing output rather than invoke paid work. W1 validates the three layers and requires topic evidence/pending questions and project purpose before candidates become ready. Four dimensions preserve null/unknown; no automatic aggregate scoring until a user profile exists. Reviews affect the stated version and retain later as deferred, not a negative taste sample.

Job payload/caller/operation ID survive restart. W1 owns bounded workers, retry ceiling/deadline, cancellation and recovery rules; W2 supplies atomic CAS in the existing SQLite transaction. Only one worker can change queued to running. Unknown external outcome is preserved as delivery_unknown and is not blindly retried. W2 will propose exact 003 DDL; only W0 writes it.
